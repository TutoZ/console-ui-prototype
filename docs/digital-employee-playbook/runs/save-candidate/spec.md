# 候选保存实现规格

主要主张 E2/E5；沿用 R01 保存不影响当前版本、R13 失败保留输入并可恢复。

入口为 design-io.html 中独立培训试跑。真实产品集成时放回员工培训工作区；这个验证入口不替换产品导航。

固定员工“售后服务专员”，当前 V1 在岗。输入只修改草稿，保存产生 V2；重复回执不得新建 V3。再次修改后保存产生新候选，旧候选不被草稿编辑改写。正在保存时禁止重复提交，返回再进入保留当前会话草稿。刷新页面恢复演示基线。

失败分支由独立折叠的测试工具注入，显示失败并保留输入；下一次重试可成功。空白输入不能保存，提示原因。所有主操作用项目 BTN_INK/BTN_SOFT，字段用 FIELD/LABEL，多行不套 FIELD_CTRL。

原子验收：AU-S01–S05 可在当前实现验证。AU-S06 的正式测试资格关联未在此实现，仍未验证；局部修改草稿不改存档的断言可以验证。组合流程测试/应用与真实权限、版本隔离仍为未执行。

布局至少检查 1366×768 与 1024×768；操作焦点可见，等待不抢焦点；保存状态有文字。构建、状态单元测试、AST导入校验与浏览器观察分别记录，不混为产品上线通过。
